# CLAUDE.md

Working rules for this repo.

## Git workflow

- Changes are committed and pushed directly to **main**.
- Never create a new branch, open a pull request, or use a branch-and-merge flow.
- Never add an AI signature/attribution anywhere ("Generated by Claude", "Co-Authored-By: Claude", etc. must never appear in commit messages or any file).
- Deploy: pushing to main automatically triggers a redeploy on Render (via its GitHub integration and/or `.github/workflows/deploy.yml`). No separate deploy step is needed.

## Language

- All developer-facing content (code comments, identifiers, docs like this file and README.md, commit messages) must be in English.
- User-facing content (the app's Turkish UI translations in `client/src/services/i18n.js`, email templates, generated report text, voice assistant output, and any other text end users see or hear) stays in its original language — do not translate it.

## Versioning

- Every commit must bump the app version (patch level) — `package.json`, `client/package.json`, and `server/package.json` stay in sync.
- This happens automatically: `.husky/pre-commit` runs `scripts/bump-version.js` before every commit and stages the updated files into it. Do not disable, bypass (`--no-verify`), or remove this hook.
- The login page displays the current version (`__APP_VERSION__`, read from `client/package.json` at build time) — it must always reflect the latest committed change.

## Project

- Backend: `server/` (Node.js + Express, ESM, run via `tsx`)
- Frontend: `client/` (React + Vite + Tailwind)
- Quantum computing: `server/quantum/` (Python + Qiskit, invoked by Node as a subprocess)
- Deployment: `render.yaml` (Render)
